# AI Agent 与后端面经题库

更新日期：2026-09-15。由 [20 篇阅读档案](interview-reading-log-2026-09-15.md) 提炼，合并重复考点后共 **87 道候选题**：RAG / Agent 50 道，Go / 后端 37 道。

## 使用方式

- 本文件是候选题库，不是一次性作业；当天仍已结束训练。每日只选 2 道 RAG / Agent（通常各 1 道）与 3 道后端，逐题展示。
- 使用前完整读取 [评分规范](interview-answer-rubric.md)。选中一道题后，再依据题面确定必答点与高级加分点；不得按该来源整篇面经的要求评分。
- 所有题目均为考点改编，不是逐字真题。来源编号对应阅读档案。B30、B31、B33 等包含面向 Go 的迁移改编，不声称原帖曾问 Go。
- 类型沿用规范；每道题聚焦一个能力点，两个相关问句仍属于一题。RAG 可用法律问答举例，不要求 LawStation 内部细节。
- 此轮保存问题，不将帖子答案当成标准答案。正式出题或评分涉及技术事实时，另用官方文档和原始论文核验；尤其不能继承帖子的错误预设（如“CHAR 一定更快”“Lua 原子性等于不丢数据”）。
- 完整技术大类已转成候选题；训练算法细节、论文数值、前端实现、Java/JVM 专项、手撕代码与个人求职问题按用户范围过滤，不以“全部入库”为由追加这些考查要求。
